# Country flag artwork

These 65 SVG files are the unmodified `flags/1x1` assets for the countries supported by `src/lib/countries.ts`.

- Source: [lipis/flag-icons](https://github.com/lipis/flag-icons)
- Pinned revision: [`086f7e97d657358203916dbe84f61c2bccaa81eb`](https://github.com/lipis/flag-icons/tree/086f7e97d657358203916dbe84f61c2bccaa81eb)
- Original path: `flags/1x1/<lowercase ISO country code>.svg`
- Retrieved: 11 October 2026

The interface crops the square artwork into circular badges using CSS. Assets are served locally, with no package or third-party image request. Country names remain visible; flags are decorative companions to country choices, never language selectors.

# Product photography

Downloaded and license-checked on 16 October 2026 for Insurance Group's public product selector. These are decorative category illustrations, not customer records, insurer endorsements or descriptions of covered activities. Product labels, preview availability and actual conditions remain separate.

All files are locally served WebP crops: 800×500 for the selected card and 240×180 for compact choices (`-thumb`). Conversion used the Sharp version already installed with Next.js; no runtime image service or new dependency. Only the selected image loads eagerly; alternatives use small lazy-loaded files. No source photo is requested from a third party by the customer's browser.

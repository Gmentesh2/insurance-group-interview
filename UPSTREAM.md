# Source and scope

This interview project reuses the Insurance Group frontend created in https://github.com/InnovationEdge/insurance-group at commit 83e0231ab6adb0e01910878fd301678029889c6c (16 October 2026). The interface, CSS design system, translations, local illustrations/flags and their attribution files are adapted from that project. The original repository and its Supabase/TypeScript backend are separate and unchanged.

This repository adds a C#/ASP.NET Core Web API, ASP.NET Core Identity password registration/login, EF Core PostgreSQL schema/migrations, private relational evidence, draft deletion and optional Gemini assistant. It is an adaptation of existing work, not an assertion that the complete interface was created from scratch during the interview assignment.

All insurance, provider, payment and certificate behavior remains fictional. Product illustrations are decorative, never endorsements or coverage guarantees. Dependency and asset licenses are retained with their sources; this private repository does not grant a blanket license to proprietary project content.
